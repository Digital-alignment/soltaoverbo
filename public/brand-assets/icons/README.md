# ícones característicos da marca — solta o verbo

coloque aqui os ícones vetoriais autorais do universo imagético da marca:

- `icone-pena-estilografica.svg` : pena clássica de tinta e caligrafia
- `icone-semente-broto.svg` : semente em germinação (metáfora de autodesenvolvimento)
- `icone-xicara-cafe.svg` : xícara fumegante em traço contínuo
- `icone-livro-aberto.svg` : páginas de caderno abertas com fitilho
- `icone-chama-acesa.svg` : chama poética ("o que queima no peito")
- `icone-maquina-escrever.svg` : máquina de escrever clássica mecânica
- `icone-coracao-organico.svg` : coração existencialista assimétrico
- `icone-estrela-quatro-pontas.svg` : estrela guia em traço manual

### especificações recomendadas:
- formato: **SVG limpo e otimizado** (sem estilos inline desnecessários, preferir `stroke="currentColor"` ou `fill="currentColor"` para que o CSS defina as cores da marca).
- viewBox padrão: `0 0 24 24` ou `0 0 48 48`
- espessura de traço: 1.5px a 2px
- para exportações raster: PNG transparente 512x512 px
