# elementos gráficos, divisores, stickers e collages — solta o verbo

esta pasta é dividida nas seguintes subestruturas:

### 1. divisores de seção (`/dividers/`)
- `divisor-linha-rasgada.svg` / `.png` : traço de papel rasgado horizontal
- `divisor-linha-costura.svg` : linha pontilhada de costura de caderno artesanal
- `divisor-traco-caligrafico.svg` : pincelada orgânica com tinta nanquim
- `divisor-seta-organica.svg` : seta desenhada à mão

### 2. stickers & fitas (`/stickers/`)
- `washi-tape-terracota.png` : fita adesiva translúcida com textura de papel (#fd5e32)
- `washi-tape-azul.png` : fita adesiva azul profundo (#140d82)
- `washi-tape-oliva.png` : fita adesiva oliva (#bec540)
- `washi-tape-kraft.png` : fita parda neutra (#dfd6bf)
- `carimbo-solta-oficial.png` / `.svg` : carimbo circular com desgaste analógico
- `selo-postal-aceso.png` / `.svg` : selo dentado com numeração vintage
- `etiqueta-vintage-preco.png` : tag de papel com barbante

### 3. collages de final de seção & ornamentos (`/collages/`)
- `collage-secao-manifesto.png` : composição com flores secas prensadas, máquina de escrever e recorte
- `collage-secao-personas.png` : sobreposição de polaroids e anotações
- `ornamento-folha-prensada.png` : ramo vegetal seco botânico
- `ornamento-clipe-metalico.png` : clipe de papel metálico vintage

### especificações recomendadas:
- formato: **PNG com transparência (canal alfa de 24 bits)** ou **SVG vetorial**
- resolução: entre 600px e 1600px de largura
- compressão: utilizar TinyPNG ou Squoosh para manter o peso inferior a 350 KB por sticker
