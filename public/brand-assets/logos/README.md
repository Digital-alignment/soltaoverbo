# logos e favicons — solta o verbo

coloque aqui os arquivos de logotipo e ícones de navegação:

### 1. logos principais (`/master/`)
- `logo-master-azul.svg` : logo por extenso na cor azul profundo (#140d82)
- `logo-master-terracota.svg` : logo por extenso em terracota (#fd5e32)
- `logo-master-negativo.svg` : logo em papel semente/branco (#ede6d4)
- `logo-master-carvao.svg` : logo em carvão (#2c2720)

### 2. monograma sv (`/monogram/`)
- `monograma-sv-azul.svg` : símbolo 'sv' em caixa azul
- `monograma-sv-selo.svg` : versão carimbo / selo circular
- `monograma-sv-terracota.svg` : símbolo 'sv' em terracota

### 3. favicons (`/favicons/`)
- `favicon.ico` : formato multi-resolução (16x16, 32x32, 48x48)
- `favicon.svg` : ícone vetorial moderno para navegadores
- `apple-touch-icon.png` : 180x180 px (png com fundo sólido #140d82)
- `favicon-32x32.png` : 32x32 px
- `favicon-192x192.png` : 192x192 px para android/pwa

### especificações:
- formato preferido: **svg** (sempre que possível) ou **png transparente** (mínimo 2000px de largura)
- modo de cor: **srgb** (telas) / **cmyk** (pastas de gráfica)
